# Agent instructions

## Project

fewbie module registry: the single authored store for fewbie items, at both
page level (`src/features/**`) and lib/component level (`src/lib/**`,
`src/components/**`). Items live under `packages/modules/` (ADR-059 in
`devbie`); each item directory carries `fewbie.module.json` and the source files it
ships, laid out to mirror the host target path.

`@devbie/fewbie-cli` ships a generated snapshot of this repository for hosts
that declare no registry (ADR-058 in `devbie`). Author every item here; the
snapshot is regenerated by a script and must never be hand-edited.

## Item admission criteria

A directory belongs here only when all of these hold:

- It contains no host business vocabulary: no product name, entity, status or
  enum of a specific host; copy arrives through `labels` props.
- It depends only on the fewbie framework surface (`@/components/ui/*`, React).
  No host i18n, router, transport, toast, or state library imports.
- It is copy-assemblable: the host renders the exported component with props
  and adds no hand-written adapter beyond the ports the item documents.
- Item files mirror their target path
  (`packages/modules/login-page/src/features/login-page/*` lands at
  `src/features/login-page/*`), so the CLI copies them verbatim.

## Registry layout

Only `fewbie.module.json` and the files in its `files` array are installed. Registry
infrastructure never reaches a host: item tests (`packages/modules/<item>/test/`), the
repository-root `harness/` (its `framework/` tree doubles the host surface that
`check:types` and vitest compile against; its `testing/` tree is repository-private and
imported as `@testing/*`), `scripts/`, and the root `package.json` / `vitest.config.ts` /
`tsconfig.json`.
`scripts/check-contract.mjs` enforces this — directory name equals
`fewbie.module.json.name`, `files` paths are safe and exist, and the on-disk payload
(minus `test/`) matches `files` exactly. Items without a `contract` warn and
skip only the contract comparison.

## Workflow conventions

- Branch: `dev`; `main` is the ref hosts pin, so merge `dev` -> `main` only
  when an item is ready to install.
- Never edit an installed copy in a host; change the item here and reinstall.
- `npm run format:check` is the pre-commit gate; `npm run format` writes with
  the devbie prettier config (2 spaces, double quotes, semicolons, 120 columns).
- This repository publishes no npm packages. Hosts consume it through
  `fewbie.json`'s `registry` declaration.
